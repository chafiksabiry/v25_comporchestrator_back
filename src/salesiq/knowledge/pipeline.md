PIPELINE REPS HARX - CE QUE CHAQUE ÉTAPE VEUT DIRE

Source : Zoho CRM, module Deals, pipeline "Reps Pipeline". Le nom du deal = l'email du candidat.
Les lignes marquées [À COMPLÉTER] ou [À VÉRIFIER] doivent être validées par l'équipe HARX
avant d'activer l'envoi automatique. Tant qu'une étape n'est pas validée, l'agent passe la main
à un humain au lieu d'inventer.


ÉTAPE 1 - REPS INSCRITS (10 %)
Ce que ça veut dire : le candidat a créé son compte sur harx.ai, mais son profil n'est pas encore complet.
Prochaine action pour le candidat : compléter son profil (CV, informations, vidéos du CV interactif). [À VÉRIFIER]
Ce que l'agent peut dire :
  "Votre compte est bien créé. Pour être visible sur les projets, il vous reste à compléter
  votre profil depuis votre espace REPS sur harx.ai."
Délai ou info à donner : [À COMPLÉTER]
Passer à un humain si : le candidat dit avoir déjà tout complété (incohérence avec le CRM).


ÉTAPE 2 - COMPLETED PROFILE (15 %)
Ce que ça veut dire : le profil est complet. Le candidat n'est pas encore inscrit à un projet (gig).
Prochaine action pour le candidat : postuler à un ou plusieurs gigs depuis l'espace REPS (onglet Marketplace). [À VÉRIFIER]
Ce que l'agent peut dire :
  "Votre profil est bien complet. La sélection se fait projet par projet : il vous reste à postuler
  à un gig depuis la Marketplace de votre espace REPS."
Délai ou info à donner : [À COMPLÉTER - qui sélectionne ? sous quel délai ? que se passe-t-il s'il n'y a pas de gig ouvert ?]
Passer à un humain si : le candidat dit avoir déjà postulé à des gigs sans réponse.
Cas réel : "inscrite depuis une semaine mais pas sélectionnée" (conversation #1702).


ÉTAPE 3 - INSCRIT AU PROJETS (60 %)
Ce que ça veut dire : le candidat a postulé ou a été retenu sur un projet. [À VÉRIFIER : postulé, ou accepté ?]
Prochaine action pour le candidat : [À COMPLÉTER - attendre une invitation ? suivre une formation ? préparer le mock call ?]
Ce que l'agent peut dire :
  "Votre candidature au projet est bien enregistrée. La prochaine étape est [À COMPLÉTER]."
Délai ou info à donner : [À COMPLÉTER]
Passer à un humain si : le candidat demande le détail ou le statut d'un projet précis.
Cas réel : "inscription à deux gigs, toujours pas de retour" (conversation #1701).


ÉTAPE 4 - MOCK CALLS (70 %)
Ce que ça veut dire : le candidat doit passer, ou a passé, un appel d'entraînement (mock call) qui évalue sa façon de gérer un appel client. [À VÉRIFIER]
Prochaine action pour le candidat : [À COMPLÉTER - comment réserver ou passer le mock call ? combien de temps ? conseils ?]
Ce que l'agent peut dire :
  "Vous êtes à l'étape du mock call : un appel d'entraînement qui permet au client de valider votre profil. [À COMPLÉTER]"
Délai ou info à donner : [À COMPLÉTER]
Passer à un humain si : demande de résultat du mock call, contestation, problème technique pendant l'appel.


ÉTAPE 5 - MOCK CALLS VALIDÉ PAR LE CLIENT (80 %)
Ce que ça veut dire : le client du projet a validé le mock call du candidat.
Prochaine action pour le candidat : [À COMPLÉTER - signature ? formation ? date de démarrage ?]
Ce que l'agent peut dire :
  "Bonne nouvelle : votre mock call a été validé par le client. La prochaine étape est [À COMPLÉTER]."
Délai ou info à donner : [À COMPLÉTER]
Passer à un humain si : questions sur la date de démarrage, le contrat ou la rémunération.

CANDIDAT INTROUVABLE DANS LE CRM
- Demander poliment l'email utilisé pour l'inscription.
- Si toujours introuvable : ne pas affirmer qu'il n'est pas inscrit. Dire que l'équipe va vérifier, puis passer à un humain.
- Si un deal porte un nom ou un email proche : ne rien dire au visiteur, le signaler dans la note interne.


RÈGLES QUI S'APPLIQUENT À TOUTES LES ÉTAPES
- Ne jamais promettre une sélection, un projet, une date ou une rémunération.
- Ne jamais donner le pourcentage du pipeline ni le nom interne des étapes au candidat. Parler simplement ("votre profil est complet").
- Ne jamais parler d'un autre candidat.
